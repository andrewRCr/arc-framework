# Cohort: `principle-anchored-core`

> _Coordination and identity record for this cohort. Membership is derived from each member's
> `Cohort` field — held here as shared coordination, never a roster. Internal-dev; not shipped._

**Parent:** [none]

**Purpose:** The work units that realize ADR-020's principle-anchored scalable core — a small, non-negotiable
principle and discipline core, with the convention layer scaling by depth and footprint rather than forking
into siloed modes. The shared thesis is **scale grammar, never scale discipline**: every member scales some
facet of ARC's _authored ceremony_ (the config surface, workflow composition, template loading, the WU
lifecycle) while holding the execution-discipline floor invariant. A grouping earns its place here only if its
work serves that thesis.
