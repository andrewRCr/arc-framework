# Reference: Session-Init Probe Envelope

The session-initialization workflow consumes this envelope. Load this reference when a slot's shape, presence
condition, or provenance is needed; procedural handling remains in the owning workflow — and so does **rule
classification**. Where a slot description states an obligation ("surfaced verbatim", "never auto-removed"), it
restates a rule the owning workflow holds; read that workflow's authority boundaries before treating the
restatement as the whole of the rule.

| Field                       | Contents                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| --------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `identity`                  | `{identity, role}` — either may be `null`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `derivedLocusState`         | **Required session-frame authority.** One worktree-derived snapshot carrying `roster`, the canonical current-checkout `entering` selector, `primaryAvailability`, `identityDiscovery`, and an optional WU-only `active` convenience. `active.context` supplies workflow, stage, session type, task cursor, cohort, and load set from the same exact meta projection. An unresolved entering row stops entry; malformed siblings remain row-local diagnostics or cleanup offers.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `locusGuidance`             | CLI-precomposed narration derived from `derivedLocusState`. `kind: unavailable` carries the entering-checkout stop message. `kind: ready` carries exact entering, primary-allocation, identity-discovery, cleanup, and diagnostic text only when present. Render every line verbatim; guidance explains evidence but adds no mutation authority.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `user`                      | Remote notes state (`value.state`: clean / remote-ahead / conflict / disabled / remote-unavailable). Carries `value.recommendedAction` ∈ `{pull, prompt, surface, skip}` and `value.recommendedPromptText` (composed channel-named offer text; empty string when not prompting) for Step 2's per-channel pull dispatch. The clean arm also carries `value.loadNeeded?: boolean` — `true` when refs match but disk lags behind the latest local note (cross-machine resume gap), feeding Step 2's notes-load dispatch; omitted on every non-clean spine state. The clean arm may additionally carry `value.notesDriftSurface?` (`{direction: edits \| modified \| mixed \| missing, register: expected \| caution}`) — a notes/disk divergence that is neither a safe auto-load nor silent local-only work; `register: expected` is calm parallel-session steady state, `caution` is inspect-before-rely; rendered in Step 6's advisory tier (D3)                                                                                                                                                                |
| `worktree`                  | Worktree sync state vs. `origin/<current-branch>` (`value.state`: clean / local-ahead / remote-ahead / diverged / no-upstream / detached-head / no-remote / branch-gone / remote-unavailable / skipped; `value.ahead` and `value.behind` populated for healthy states). Carries `value.recommendedAction` / `value.recommendedPromptText` mirroring the user slot. Also carries `value.identity` (`kind`: `primary` or `linked`, plus `path` when linked) — the physical worktree the session occupies, surfaced in orientation only when `linked`. In the `diverged` sub-state also carries `value.supersession` (`{superseded, supersededCommits, novelCommits}`, else `null`) — patch-equal supersession of the local-ahead commits; when `superseded`, Step 6's diverged arm renders the lossless-reset downgrade                                                                                                                                                                                                                                                                                           |
| `currentHusk`               | Optional derived orientation for the current linked branchless worktree. `value` is `null` unless a structurally valid WU husk stamp matches live `HEAD`; a match always carries the exact path, WU subject, stamped branch, and discriminated `stamp`. `stamp.kind == current` carries authorization, authoritatively revalidated evidence, and persisted remote proof; `legacy` carries only the compatibility authorization (`merged-preserved`) and grants no remote-delete authority; `manual-only` carries only its reason. Failed revalidation falls back to ordinary detached-HEAD guidance. Probe degradation and every non-linked or branched checkout omit the slot                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `baseDistance`              | Shared advisory base-drift analysis against a freshly fetched immutable `branch.base` OID. `value.mode` is `advisory`; `value.verdict` is `clean` / `reconcile` / `unavailable` / `skipped`; compatible `state`, `ahead`, `behind`, `base`, and optional `failureReason` remain. Healthy readings carry `baseOid`, typed `integrationEvidence`, typed `overlap` (`available` with substantive/regenerable paths or `unavailable` with a reason), and an analyzer-owned `register`; unavailable readings carry `unavailableReason`. `recommendedAction` is `surface` only for `reconcile`, with `recommendedPromptText === register.text`; every other verdict is `skip`. Advisory only: surfaced verbatim in Step 6 and never gates or reconciles.                                                                                                                                                                                                                                                                                                                                                              |
| `baseBranchSync`            | Base-branch-sync state — local `<base>` vs `origin/<base>` (`value.state` reuses the worktree enum; `value.ahead` / `value.behind` / `value.base` populated when healthy). Also carries `value.checkout` as an object (`kind`: `not-checked-out` / `current` / `elsewhere` / `unknown`; optional `path` and `primary` on `current` and `elsewhere`) — where the local base is held. The silently-stale-local-base surface, sibling to `baseDistance` (HEAD vs `origin/<base>`). Carries `value.recommendedAction` / `value.recommendedPromptText` — config-gated by `session.init_pull.base`: `pull` / `prompt` only when the base is not checked out (`git fetch origin <base>:<base>`); `surface` a stale base under `manual`, a base checked out elsewhere (primary-aware), checkout location unknown, or diverged; `skip` a current base or when this worktree holds the base. Current-worktree dirt does not gate this channel                                                                                                                                                                             |
| `dirty`                     | Working-tree state from `git status --porcelain` (`value.state`: clean / dirty; `value.fileCount`). Folded into the user/worktree `recommendedPromptText` so Step 2 doesn't re-probe                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `extensions`                | `value.active`: the **active-extensions list** — consulted by fire-point directives in downstream workflows                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `config`                    | `value.settings`: session-relevant settings (`session.remote_sync`, `session.init_pull.worktree`, `session.init_pull.notes`, `session.init_load.notes`, `branch.protection`, `pm.mode`, `commit.format`, `commit.context_footer`, `commit.interlock`, `push.interlock`)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `active`                    | WU-only convenience derived from `derivedLocusState.value.active`. `resolution` is `single` only for an entering WU with resolved context and `none` otherwise; it never exposes repository-wide candidates or performs another active-meta read.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `currentWuReconcile`        | Optional read-only current-WU reconcile projection, present exactly when `active.value.resolution == single`. `value.status` is `clean` / `pending` / `conflict`; dependency facts, tracked-reference edits, and advisories share the current-WU reconcile contract. `value.recommendedAction` is `surface` for pending or conflict and `skip` for clean; Step 6 renders `value.recommendedPromptText` verbatim and never applies tracked edits.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `userReferenceReconcile`    | Optional read-only identity-global user-reference projection, present for a resolved identity and single active WU. `value.status` is `clean` / `pending` / `advisory` / `unavailable` / `conflict`; `value.plan` carries exact managed `WU_Target` edits plus advisory findings. `value.recommendedAction` is `apply` only for authoritative unambiguous rename repairs, `surface` for advisory/degraded authority, and `skip` for clean; Step 2 invokes only the CLI-owned `recommendedCommand`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `taskCursor`                | Optional deterministic task-list cursor copied from the entering WU's `active.context`. On success, branch on `taskCursor.value.status`; `found` supplies a line-anchor helper, `no-open-task` skips the strategic read, and `malformed` / `missing` surface the CLI-owned diagnostic. No second task-list cursor read occurs in session composition.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `domainRules`               | `value.rules`: `{path, domain, purpose}` tuples from `DEV-RULES.{DOMAIN}.md` files; `value.warnings`: frontmatter parse diagnostics                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `releaseRouting`            | Resolved `taskCommit`, `workflowCommit`, and `workflowPush` routing (`wrapper` or `raw`) plus rationale. Workflow class-tag fire sites consume this slot; it does not select session state.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `loadSet`                   | Ordered `LoadSetManifest` copied from the entering WU's `active.context`; it is projected once with every active extension. When no entering WU resolves, the slot contains only the universal/personal between-WUs set. A transient row carries no WU context, so this slot is never its owning workflow's load set.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `recommendedCombinedPrompt` | Top-level. Composed combined-prompt text when both `worktree` and `user` resolve to `recommendedAction === "prompt"`; `null` otherwise                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `recovery`                  | Pre-computed branch-gone recovery resolution; present only on the `branch-gone` arm when `roster` resolved. Exact `resolved` / `surface` / `main-fallback` arms carry `remoteEvidence: exact` and retain their candidate actions. The `pending` arm carries `remoteEvidence: pending-fetch`, verified candidates, a positive unseen-tip count, and the structured live-refresh remedy. Every arm carries CLI-composed `recommendedAction` (`switch` / `prompt` / `surface`) and `recommendedPromptText`; Step 2 dispatches those fields without comparing evidence or counts. Pending offers only refresh or manual recovery.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `sweep`                     | Pre-computed residue sweep. Primary sessions use the public roster; identity-known linked sessions use a private cleanup-only roster and exclude their exact current path; team-mode linked sessions with unresolved identity omit that private read. `value.worktrees` is a discriminated union: `branched` reports preserve the existing decision; every report's decision is first checked against derived checkout authority (`blocked` / `locus-occupied` for an occupied derived role, `blocked` / `locus-unverified` when authority is unresolved); `husk` reports always carry path, typed subject, stamped branch, decoded `stamp`, nullable `completedWorkUnit`, and the exact-stamp cleanup decision. Only `stamp.kind == current` carries authorization/evidence/remote proof; `legacy` carries compatibility authorization, and `manual-only` carries a reason. `value.retirements` carries receipt-backed actionable/blocked cleanup plus typed teardown and successor actions; `value.renameMoves` carries exact validated outside-worktree move actions. Surfaced in Step 6; never auto-removed |
| `orphanBranchSweep`         | Pre-computed local orphan-branch sweep; present in primary and identity-known linked sessions. `value.orphans` remains `{branch, merged, shippedWorkUnit}` for type-prefixed local branches whose upstream is `gone`, excluding checked-out and errand-record branches. Step 6 offers `arc teardown` for a shipped orphan, an interlock-gated `git branch -d` for a merged one, and surfaces the rest as not-removable (never `-D`). Branch hygiene; never auto-removed                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `retiredSubdirs`            | Pre-computed retired-subdir detection. `value.candidates`: retired-WU user subdirs lingering under `user/{identity}/` — shipped and carrying no unpushed local drift. Present whenever identity resolved; omitted only when identity is absent. Enriched with `recommendedAction` / `recommendedPromptText` (gated on `session.init_load.notes`): init may reconcile under policy via Step 2's notes-load dispatch (removal + `.internal/` backup inside `arc user load`); `manual` stays warn-only (Step 6)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `errandSweep`               | Pre-computed reminder sweep. `value.stale`: `_Remind:_`-flagged `§ Errand` `USER-INBOX` entries pending past `inbox.remind_after_days` (default 1), each with `slug`, `created`, and `ageDays`. Present whenever identity resolved (the inbox is identity-scoped — not worktree-gated, unlike `sweep`); omitted only when identity is absent. Read-only advisory surfaced in Step 6 as a once-per-calendar-day batched nudge — drain via housekeep; never auto-removed                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `errandState`               | Pre-computed errand-state probe. `value.resume`: current-branch resume signal (`resumable`, `slug`) on meta-less `chore/` branches. `value.residue`: Orient-only branch/identity cleanup advisories (`branch`, `slug`, `reason`, optional degradation `marks`). `value.inFlight.errands`: Orient local/remote advisory over `chore/` branches (`in-progress` / `awaiting-merge` / `merged-cleanup` / `stale`). `value.materializable.candidates`: remote-only v3 identities in `paused` or `awaiting-merge` state with matching branch evidence and no local branch/worktree; each carries `slug`, `claimId`, `branch`, `expectedHead`, `state`, and `originEntry`. Branches without an exact identity never authorize materialization. `value.nudge`: once-per-calendar-day marker state (`shouldNudge`, `markerPath`, `today`) shared by reminder and stale-errand surfaces. Present if worktree + active probes resolved.                                                                                                                                                                                    |
| `materializableWorkUnits`   | Pre-computed materialize-candidate set. `value.candidates`: the operator's remote-only in-flight work units (branch + committed meta on the remote, no local branch or worktree), each `{name, branch}` — the discovery surface the Materialize arm offers for cross-machine pickup. Present ONLY on the no-active-WU arm (`active.resolution === "none"`), where the oracle's network slice fires; the resume path omits it (zero oracle cost). An empty list means the oracle ran and found none (or the remote was unreachable)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `workUnitState`             | Pre-computed work-unit completion sweep over the operator's owned in-flight (`Integrating`) WUs, each classified across the tail (`awaiting-review` / `mergeable` / `blocked` / `merged-needs-archival` / `stale`) with a `behindBase` qualifier and whole-day `ageDays`. Present on the roster-resolved arms (primary / no-active-WU / branch-gone). `value.nudge` carries the once-per-calendar-day marker state gating the batched `stale` surface; the `mergeable` / `merged-needs-archival` events bypass it and surface every session-init. The presence tier is network-free; the mergeable-sharpening tier (live PR via `gh`) fires only on no-active-WU and degrades to presence when `gh` is absent                                                                                                                                                                                                                                                                                                                                                                                                   |
| `inFlightComposition`       | Pre-computed in-flight `Class` composition — `{novel, heavy, light}` resolved-`Class` counts over the in-flight roster slice (`[TBD]` / field-absent excluded). Present only on the no-active-WU arm when the slice is non-empty; consumed by Step 5's next-work discovery to render the concurrent-workload advisory                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `cohortDocPath`             | Path copied from the entering WU's `active.context` when its exact meta resolves a coordinating cohort doc; omitted otherwise. Read in Step 3's context-load (item 11).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `inboxState`                | Pre-computed inbox-state probe. `value.routableCount` counts routable (well-formed, non-held) `USER-INBOX` entries; `value.housekeepNeeded` is true when that count > 0. Present whenever identity resolves (the source is identity-scoped); omitted only when identity is absent. The Orient arm reads the housekeep signal.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `partialPushMarker`         | Pre-computed partial-push-marker surface — consumer of the cohort sibling's sync-state ref. `value.markers`: live, non-expired markers, each a sibling notes push not yet arrived at origin (lag, not loss), carrying `machineId`, `lastAttemptedCommit`, `attemptTimestamp`. Present whenever identity resolved; omitted only when identity is absent. Offer-only — render `arc user compact` when over threshold and nudgable; never auto-run                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |

**Raw notes-ref topology on `user.value.refState?`**: The notes spine's 5-state `value.state` enum encodes
pull-direction dispatch and collapses `same`, `local-ahead`, and diverged `remote-subset` content into `clean`
(all mean "no pull needed"). The parallel `value.refState?` field preserves raw topology (`same` /
`local-ahead` / `remote-ahead` / `diverged` / `remote-unavailable`; omitted only when `state == "disabled"`),
while `value.contentRelation?` preserves the diverged tree relation. Step 6 reads both inside the `clean` arm to
distinguish the collapsed cases for orientation surfacing.

**Interlock-mode keys on `config.value.settings.{commit.interlock, push.interlock}`**: Both are
git-config-resolved from `arc.commitInterlock` / `arc.pushInterlock` (with documented defaults when
unset) rather than yaml-sourced. Load-bearing for prompt-prefix composition at any commit or push
fire site — see DEV-RULES.ARC § Implied-approval scope for the prefix mapping.
