# Shared work-item rules

`checkFormerSlug` protects a former name held by another generation during a creation or rename. Name acquisition
reads the prior primary identity, so it works for both metas and Errand records independently of their field parsers.

All observations use the supplied before and after views. Unavailable identity evidence remains a rule refusal with
an actionable remedy; a proved missing slug is available for creation.

`checkSlugEdges` requires a batch reusing another generation's slug to settle each surviving dependency edge that
named it before the batch. It reads completed primaries and retired-origin lineage distinctly; missing primary
records alone do not establish retirement. Archived or removed dependents gate no write. Incomplete enumeration or
edge reads preserve a refusal and its repair route.
