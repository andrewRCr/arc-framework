# Review evidence

One record retains an approved disposition set and the result it answers, with a Candidate, Errand, member, private
member owned by a Candidate, or no response binding. The outcome key and result digest replace legacy source references.
Optional fix tags remain outside canonical disposition and approval identity, and historical absence stays absent.

Performance combines the lane response and an Errand or member's complete fix response in one atomic value. Its fix
authorization derives from the canonical approval and original target; only the consumption is retained. Candidate
performance may bind its response digest. Hosted settlement retains the set's finding actions and per-finding evidence,
including carry from its direct predecessor.

The parser validates the canonical approval, ownership and target-transition facts held in the record, pending policy
projection, and per-set settlement. The referenced outcome supplies the exact producer source and original lineage;
those comparisons belong to admission rather than content parsing. Shared hosted-settlement rules also validate the
legacy aggregate binding.
