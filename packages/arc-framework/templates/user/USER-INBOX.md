# User Inbox

> _Personal capture surface for items to handle later. Drain destination depends on the project's PM mode.
> See `strategy-session-operations.md` § USER-INBOX. Capture via the `arc-inbox` skill._

## Errand

> _Errand-class captures — a single self-evident concern below the spec-worthiness floor (nothing worth recording
> as design, no durable plan a correct execution must navigate). Always atomic: one indivisible concern bounded
> to a single session — typically one review increment, though a determinate sweep may run a bounded few
> in-session passes (an extended errand). Drain to execution — folded into a WU (inline absorption), or run as an
> errand via `arc-session --errand`, from the primary worktree's base, never a WU branch._

## Work Unit

> _Spec-worthy captures — clearing either intrinsic floor (a design worth recording, or a durable plan a correct
> execution must navigate); bound for a backlog stub. Route to an existing stub, or graduate to a new one
> — directly at housekeep; `arc-session --errand` only if needed mid-WU. Carries `WU_Target` (TBD ok); an optional
> `(planned|provisional)` parenthetical sets a new stub's dir (decided at drain if omitted)._
