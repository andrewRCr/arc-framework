# Whole-gate qualification

`runGateChild` runs one forced production gate from a fixed, clean checkout and retains its raw report, native
observations, provider timings and interrupted capture handles outside that checkout. Supply an explicit `GateTrial`;
use independent checkouts for concurrent controllers.

The routed baseline changes only eligible in-memory shard expansion. Distributed trials retain declaration defaults;
native-local trials provide context when observed machine policy permits local execution. Both measured arms use the
same source, native selection, explicit inputs and complete requested check set.

`summarizeGateSamples` keeps every sample and reports median/range and concurrent makespan only for complete,
equivalent gates with qualified native coverage. Unknown adapter runtime stays unknown; mixed native profiles require
separate real corroboration. These artifacts carry observations rather than check-pass or reuse authority.
