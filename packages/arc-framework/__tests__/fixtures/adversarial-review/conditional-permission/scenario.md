# Scenario: Conditional Additional-Pass Permission

Each branch begins after criteria-validation Pass 2 of 2 surfaced a confirmed `major`. The complete disposition set
was approved with a fix response. In the same turn, the Owner separately stated: "Authorize criteria-validation Pass
3 after this approved response is complete." Treat the branches independently.

## Branch A — response pending

The approved fix is still being implemented and has not been verified or committed. No decision has been withdrawn.

## Branch B — permission withdrawn

Before response completion, the Owner explicitly withdraws the Pass 3 authorization. The response later completes.

## Branch C — response complete, then replay

The approved response completes, its produced artifact is current, and its activity/pass bindings still match. Pass 3
is invoked and returns. Later, after Pass 3's response is settled, the old authorization statement is replayed as a
purported basis for Pass 4.

For each branch, decide whether the permission is retained, usable, invalid, or consumed and whether an evaluator may
run.
