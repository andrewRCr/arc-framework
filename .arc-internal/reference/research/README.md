# Research Documents - Framework Development

Technical research and analysis documents that inform ARC framework decisions.

## Purpose

Research documents capture investigation findings, comparative analysis, and exploration that may:

- Inform ADRs (framework design decisions)
- Guide strategy development
- Provide reference material for framework improvements
- Document patterns observed in real-world framework usage (e.g., CineXplorer)

## Naming Convention

Files are named: `research-topic-description.md`

**Examples:**

- `research-workflow-naming-patterns.md`
- `research-template-placeholder-formats.md`
- `research-ai-context-optimization.md`

## When to Write Research Docs

Write a research document when:

- Investigating framework design patterns from other projects
- Comparing multiple approaches to framework organization
- Documenting findings that don't fit in an ADR
- Capturing context from real-world usage (CineXplorer refinements, user feedback)

## Relationship to ADRs

Research documents often precede ADRs:

1. **Research** explores options and gathers data
2. **ADR** records the decision made based on research

Research may also stand alone when no decision is needed but the information is valuable.
