# Reference

Lookup-oriented pages for specific ARC topics. Unlike the [guide pages](../index.md), which
form a reading path through ARC's concepts and workflows, reference pages are destinations you
arrive at with a specific question.

Each page covers its topic at guide level: what it is, how it works, and how to use it. For
exhaustive detail, the in-repo strategy documents in `.arc/reference/strategies/` are the
canonical deep-dive; they ship with every ARC installation and are referenced by the agent
during sessions. Reference pages here point to the relevant strategy document where applicable.

| Page                                      | What You'll Find                                                            |
| ----------------------------------------- | --------------------------------------------------------------------------- |
| [Configuration](configuration.md)         | Customization mechanisms, config settings, methods, extensions              |
| [Quality Gates](quality-gates.md)         | The three-tier verification system and when each tier runs                  |

| [Team Coordination](team-coordination.md) | Multi-developer patterns, task ownership, branching, external trackers      |
| [Glossary](glossary.md)                   | Definitions of ARC-specific terms used throughout the documentation         |
