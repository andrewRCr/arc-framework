# Project Documentation (Example)

This example shows how the ARC system `_docs` structure supports coordinated AI-human development in a project.

- Start with META-PRD, PROJECT-STATUS, TECHNICAL-ARCHITECTURE, and DEVELOPMENT-RULES
- Use workflows in ./workflows to create structured Sub‑PRDs and task lists
- Limit AI autonomy to individual sub-tasks within approved task lists
- Maintain constant human oversight through session management and approval workflows
- Keep notes/ untracked in adopting projects if desired
